Smart Self-Checkout Web App
1) Overview

This is a modern, self-checkout e-commerce web application designed to reduce waiting time at billing counters.
Users can scan/select products, add them to cart, complete payment, and get a digital receipt with QR code — all in one smooth flow.

2)Features

Modern Apple-style UI (Glassmorphism)

Dark Mode / Light Mode toggle

Responsive product grid

Sliding cart sidebar

Add / remove / update cart items

Coupon & discount support

Checkout & payment screen

Digital receipt with QR code

Smooth animations & micro-interactions
